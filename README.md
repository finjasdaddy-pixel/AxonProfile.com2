# AxonProfile
A Next.js profile and badge platform starter for GitHub + Vercel.

## Quick start
1. Install Node.js 20+.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local` and fill in Supabase values for real authentication.
4. Run `npm run dev`.
5. Follow [SETUP.md](./SETUP.md) for Supabase, Google/Apple OAuth, database, and admin setup.

The app includes profile/dashboard pages, a 16-badge catalogue, badge redemption UI, Supabase auth entry points, and a server-side admin ban-record API. OAuth and database-backed features require credentials/configuration in your own Supabase/Vercel accounts.
